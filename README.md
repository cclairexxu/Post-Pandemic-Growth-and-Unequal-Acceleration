# Post-Pandemic Growth and Unequal Acceleration — ASA DataFest 2026

## Description
Analyzed a real-world healthcare dataset from Stormont Vail Health to examine a time series analysis of patient encounter dynamics across a regional health system (2022–2025), examining post-pandemic growth trends and racial disparities in healthcare utilization. Uses data visualization to describe and compare linear trends in healthcare encounter volume across demographic groups.

## Files

## Visualizations
Charts and graphs highlighting post-pandemic growth in patient encounters and unequal increases in healthcare service use across patient demographics
